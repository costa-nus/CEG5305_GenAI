PART A

A brief history of prompting

Nineteen methods on one math question. Key message: From text completion to agent, the tech of prompting is more and more complicated to resolve the complicated tasks.

One math question from GSM8K (Cobbe et al., 2021) runs through nineteen methods. A single call grows from the question alone to an instruction, solved examples (Brown et al., 2020) and written steps (Wei et al., 2022). Many tries help when a checker or a vote picks the answer (Cobbe et al., 2021; Wang et al., 2023). Prompts move into a system role (OpenAI, 2023), and then LLMs write and optimize them (Zhou et al., 2022; Yang et al., 2024; Yuksekgonul et al., 2024). Tool use follows: function calls (Schick et al., 2023), ReAct and Reflexion (Yao et al., 2023; Shinn et al., 2023) and MCP (Anthropic, 2024). Then context engineering (Karpathy, 2025), agents that edit their own context (Zhang et al., 2025), agent libraries, multi-agent systems (Hadfield et al., 2025), agents with memory (Packer et al., 2023), and agents that improve agents (Zhang et al., 2025). Each method fixes the limitation of the one before it; each slide shows the OpenAI API code.

PART B

Prompt to think

The model writes more before it answers. Key message: A reasoning trajectory cannot be trained token by token, thus prompting is the essential tool to steer the reasoning.

This part follows the lecture Inference-time techniques for LLM reasoning by X. Chen (2025). Better prompts for one chain. Then many chains, with a vote or a verifier (Wang et al., 2023; Yao et al., 2023). Then revising the chain with feedback. Last the limits: chain-of-thought helps most on math and symbolic tasks (Sprague et al., 2025), and the written chain does not always show the real reason (Turpin et al., 2023).

PART C

Prompt as System: Agents and harness

The model in a loop, and the system around it. Key message: Harness is essential when an agent becomes a complicated system with constraints, tools, failure control, etc.

This part follows the lecture What are agents? And how do they work? by Fried and Neubig (2026a): an agent is a model in a loop; each of its abilities can come from the harness or from training; agents are systems. The part then uses pages from two later lectures of the same course: context that grows on every call and how to compact it (Neubig, 2026), and agent safety, with threat models, sandboxes, limited tokens and monitoring (Fried and Neubig, 2026b).

Practice homework (no course credit)

This is practice homework. It carries no course credit and is not marked. Demo code: two_agent_demo.py · Colab notebook.

Two agents talk. Each agent is a model with its own instructions, and the reply of one is the input of the other. The demo code plays a patient and a counsellor in a first counselling session. It is a class role-play with two simulated roles, not medical advice: do not type your own problems into it. This homework is optional practice and carries no course credit.

  1. Run the demo. Get two_agent_demo.py, or open the Colab notebook. It uses the OpenAI Agents SDK and needs an API key for an OpenAI-compatible model; set OPENAI_BASE_URL to use another server. How the course gives access will be posted here.
  2. Predict, then run. Write your predictions with probabilities before you run. For example: Will the patient stay in role for six rounds? Will the counsellor give advice? In which round does the talk end?
  3. Choose one piece to change and change only that:
    • The scenario: patient and counsellor, customer and support agent (with a tool), interviewer and candidate, tutor and student, or two neighbours. Or write your own.
    • The turn limit and the stop word: when does the talk end?
    • The history: does each agent see all earlier messages, or only the last two?
    • A guardrail: a check on one agent's message before the other replies.
    • One sentence of an agent's instructions, or the temperature.
  4. Compare. Run each version 3 times. Compare the number of messages, how the talk ended, role-break hints and tokens. Check that the difference is larger than the spread across your 3 runs, and read the whole transcript before you trust a count.

Write at most 300 words: your predictions, three findings ranked, and one result you did not predict, explained. AI tools are allowed.
