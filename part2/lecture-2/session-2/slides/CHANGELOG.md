First version of the deck, for the class of 21 Oct 2026. Prompting LLMs: how far can a fixed model go?

- Invited talk by Zeyu Qin (HKUST), and an announcement of next week's guest lecture by Zechen Zhang.
- Part C, agents and harnesses: how capable agents are, what an agent is, harness or training, agents are systems, context and safety.
- Strengths and weaknesses of each setting, a practice homework with two agents (no course credit; code and Colab notebook), and the lecture summary.
